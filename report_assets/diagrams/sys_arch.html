CareerConnect 3-Tier Layered Architecture
1. Presentation Layer (Client Side) React 19 + Vite 8 SPA
Candidate Portal
Dashboard, Profile, Resume Import, Saved Jobs
Recruiter Hub
Company, Job Postings, Application Review
Admin Console
User Management, Verification, Telemetry
Public Marketplace
Home, Search, Details, Auth Pages
Route Guards & Context
ProtectedRoute, AuthContext, ThemeContext
▼ HTTP / REST APIs (JSON & Multipart via Axios with JWT Bearer Interceptor) ▼
2. Security & Gateway Filter Layer Spring Security 6
JwtAuthFilter
Header Token Extraction & Validation
SecurityContextHolder
Stateless Principal & Role Context
CORS Configuration
Allowed Origins & Pre-flight Handlers
Role-Based URL Matchers
hasRole('CANDIDATE' / 'RECRUITER' / 'ADMIN')
▼ Authorized Requests ▼
3. Application Controller & DTO Layer Spring Web MVC
AuthController
Register, Login, Google OAuth
CandidateControllers
Profile, Education, Experience, Skills
ResumeController
/resume/parse & /resume/import
RecruiterControllers
Jobs, Applications, Company, Interview
AdminControllers
Dashboard, Users, Companies, Moderation
▼ Service Invocation & Bean Validation ▼
4. Business Logic & Processing Layer Spring Service Layer
ResumeImportService
Pre-Validation & 5-Field Deduplication
DocumentParserService
PDFBox & POI Text Extraction
ApplicationService
State Transitions & Status History
InterviewService
Meeting Links & Schedule Coordination
JobExpiryScheduler
Automated Deadline Cleanup Cron
▼ Transactional Persistence (Spring Data JPA) ▼
5. Data Persistence Layer Hibernate ORM & MySQL 8.0
User & Profile Tables
users, candidate_profiles, recruiter_profiles
Candidate Portfolio
educations, experiences, skills, projects, certs
Recruitment Tables
companies, jobs, applications, status_history
Interviews & Bookmarks
interviews, saved_jobs, candidate_skills
